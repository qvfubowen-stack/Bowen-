【本地启动命令】
  唯一推荐的包管理器：pnpm 10.34.5（版本由 package.json 的 packageManager 字段锁定）
  环境要求：Node >= 18.18.0，pnpm >= 10.16.0（推荐 10.34.5）

  推荐路径：
      cd website
      pnpm install --frozen-lockfile     # 首次，约 6 秒，无任何警告
      pnpm run dev                       # 一条命令启动

  本机没有 pnpm 时：corepack enable（Node 自带，会按 packageManager 自动拉取）

  原开发机没有全局 npm 时的备选（兼容层，不支持 install）：
      cd website
      npm run dev           或           node tools/npm-run.mjs dev

  手机端在局域网内访问：
      cd website
      pnpm run dev:host
      然后用手机浏览器打开 http://<你电脑的局域网IP>:3000

  全新 clone 后如需跑图片验收测试，先执行一次（约 30 秒）：
      node tools/extract-product-images.mjs

  生产模式（可选，验证构建产物）：
      cd website
      npm run build
      npm start

  注意：首次运行前需要安装依赖（仓库不含 node_modules）：
      cd website
      npm install          （或 pnpm install）
