【本地启动命令】
  方式一（推荐，一条命令）：
      cd website
      npm run dev

  方式二（本机没装 npm 时同样可用）：
      cd website
      node tools/npm-run.mjs dev

  方式三（已装 pnpm）：
      cd website
      pnpm run dev

  手机端在局域网内访问：
      cd website
      npm run dev:host
      然后用手机浏览器打开 http://<你电脑的局域网IP>:3000

  生产模式（可选，验证构建产物）：
      cd website
      npm run build
      npm start

  注意：首次运行前需要安装依赖（仓库不含 node_modules）：
      cd website
      npm install          （或 pnpm install）

【本地访问地址】
  http://localhost:3000
  开发服务器默认端口 3000（package.json 里固定 -p 3000）。

  · 网站数据集构成：711 条 application / 2,787 条 OE 索引 / 277 个产品有多个 OE
  · 完整产品数据库（含未上线状态）：451 个产品 / 802 条 application / 3,024 条 OE 索引

  按网站产品架构分布（全部为真实产品，无空分类）：
      Thermostats（核心）      259 个
      Automotive Switches       75 个（热敏 4 / 机油压力 37 / 刹车灯 17 / 倒车灯 17）
      Temperature Sensors       41 个
      Related Cooling Parts      3 个

  为什么首页重点展示 20 个：需求要求从信息最完整的数据里挑 15–20 个真实产品作为
  prototype_candidate。这 20 个产品合计 81 条 application、758 条 OE 索引记录。
  23 个疑似字段错位的产品 blocked，47 个数据不足的产品 draft，
  这两类**完全不对外展示**，也没有出现在网站数据集里。
