修复 npm 兼容层的 3 个真实缺陷（均在实测「npm run dev」时暴露）
- npm.cmd 里的 "where npm" 会解析回 npm.cmd 自身，导致
  "Maximum setlocal recursion level reached" 无限递归 → 去掉该检查
- npm.cmd 用 UTF-8 写中文注释，cmd.exe 按 OEM 代码页解析导致注释被当命令执行
  → 改为纯 ASCII，并在文件里写明原因
- 兼容层不认 "npm run dev" 的 run token（报「未知脚本: run」），
  且 cmd.exe 继承的 PATH 里没有 node → 剥离开头的 run/run-script，
  并把 Node 自身所在目录与 node_modules/.bin 一起放进 PATH
- npm-run.mjs 增加 --list，并改进用法提示
